    Selected work

    Four things I've done that I can talk about in detail. Anything specific to my employer's environment or detection logic stays off this page, so if you want the methodology, ask me and I'll walk you through it.

    1. 01 Emulate Monthly Cymulate simulations across network and endpoint, plus retesting penetration test findings. Find the gap ourselves.
    2. 02 Detect Which rules fired, which stayed quiet, and how long the alert took to surface. A control nobody tested is a guess.
    3. 03 Investigate Tier III escalation from detection through containment, then the post-incident review and the root cause behind it.
    4. 04 Tune Rewrite the rule, cut the false positives, and re-test it against the next simulation rather than assuming it improved.

    The loop runs continuously, and each pass through it should make the next one quieter.

    Emulating the attack to test whether the detection actually fires

    I run monthly Cymulate breach and attack simulations across network and endpoint, and I retest penetration test findings rather than trusting the remediation ticket. Both are the same idea from opposite ends: the only honest way to know a control works is to trigger it on purpose and watch what happens. The point is to find the gaps ourselves, before someone finds them for real.

    Surfaced and closed 25% more control gaps than alert-driven review alone, and confirmed every high and critical penetration test finding was closed across 150+ retests.

    Control gaps surfaced +25%
    Pentest findings retested 150+

    Cutting false positives without losing signal

    I tune Microsoft Sentinel detection rules with one goal: fewer alerts nobody acts on, and better coverage where it counts. Reducing noise is only useful if the detections that matter keep firing, so every tuning change gets re-tested against the next simulation run rather than assumed to be an improvement.

    30% reduction in false positive alert volume, with higher fidelity on critical attack vectors.

    False positive volume -30%
